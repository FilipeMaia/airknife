# airknife

3D-printable dual "air knife" nozzles for blot-free sample spreading on a manual/gravity cryo-EM plunger, plus an air shutter that keeps the air out of the cryogen.

Instead of blotting with filter paper, two thin sheets of air sweep both faces of the grid just before it is plunged, thinning the liquid film. The idea follows the pressure-wave spreading module of EasyGrid:

> Gemin, O., Armijo, V., Lecomte, L. *et al.* EasyGrid: a versatile platform for automated cryo-EM sample preparation and quality control. *Nature Methods* 23, 1359–1367 (2026). https://doi.org/10.1038/s41592-026-03127-5

All parts are generated by parametric Python scripts (no CAD program needed). Pre-generated STL files are included for convenience; regenerate them from the scripts whenever you change a parameter.

> **Status:** experimental lab hardware, developed iteratively for one specific plunger. Check every clearance on your own setup before use (see [Adapting to another plunger](#adapting-to-another-plunger)).

## Current design (recommended)

**`airknife_fork_shutter.py` → `fork_shutter.stl` + `shutter.stl`**

One bracket, bolted to the breadboard behind the plunger, that carries:

- **Two downward nozzles**, one on each side of the grid, blowing down across the grid faces (35° to the face, 13 mm from the grid). The gas enters through a Festo QSM-M5 fitting and splits symmetrically to both nozzles.
- **A sliding air shutter** just under the grid (top ~8 mm below the grid's lower edge) that catches the downward air so it never reaches the ethane/LN₂.

The shutter is pulled open by a string connected to the plunger's own release solenoid. The solenoid releases the plunger after 20 mm of its 23 mm stroke; with the string taut, those first 20 mm already pull the shutter clear of the tweezer, so the shutter is open **before** the grid starts to fall. Two small rubber bands pull the shutter closed again.

It reuses the fork geometry from `airknife_breadboard.py`, so that file must stay in the same folder.

## Generating the STL files

The scripts need Python ≥ 3.10 with [`manifold3d`](https://github.com/elalish/manifold) and `numpy`. Each script carries inline [uv](https://docs.astral.sh/uv/) metadata, so the easiest way is:

```bash
uv run airknife_fork_shutter.py                 # writes fork_shutter.stl, shutter.stl, ...
uv run airknife_fork_shutter.py shutter_z=-12   # override any parameter as key=value
```

Without uv:

```bash
pip install manifold3d numpy
python airknife_fork_shutter.py
```

Every run prints a short report: clearances between the parts and the moving plunger (grid, tweezer, lock ring, holder) swept over the full stroke, the light-path clearance, the gas path, where the bolt holes land on the breadboard, and so on. Warnings are marked with `<--`.

### PLA vs resin

The nozzle slots default to resin/SLA dimensions. For FDM printing in PLA, use a wider slot and thicker lips:

```bash
uv run airknife_breadboard.py slot_g=0.6 lip=1.0
```

`airknife_fork_shutter.py` already passes these PLA values to the fork (`fork_args="slot_g=0.6 lip=1.0"`).

### Coordinate system and main parameters

All scripts share one coordinate system (millimetres):

- origin = grid centre with the plunger **up** (spreading position)
- +z up; x = grid normal (the light/camera axis); y = along the grid face, away from the breadboard
- breadboard surface at y = −`bb_dist`

Defaults are the measurements of the setup this was built for:

| Parameter | Default | Meaning |
|---|---|---|
| `bb_dist` | 86.5 | breadboard surface → plunge axis |
| `hole_u`, `hole_z` | −7.5, 0 | position of any breadboard hole relative to the plunge axis (`hole_u` positive to the right when facing the board) |
| `pitch` | 25 | breadboard hole pitch (25.4 for 1/4-20 boards) |
| `stroke` | 67 | grid travel during the plunge |
| `shutter_z` | −10 | shutter mid-plane below the grid centre |
| `sol_stroke`, `pre_release` | 23, 20 | release-solenoid stroke, and stroke at which it releases the plunger |
| `ring_top`, `ring_h`, `ring_w`, `ring_t` | 62.5, 13.5, 13, 8.4 | tweezer lock ring (top height above grid, height, width, thickness) |
| `tw_w` | 9 | tweezer width along the grid face |
| `theta`, `standoff` | 35, 13 (fork) | nozzle angle to the grid face, nozzle exit → grid distance |

See the top of each script for the full, commented parameter list.

## Printing

Tested on a Bambu Lab A1 with PLA (0.4 mm nozzle, textured PEI).

**Bracket (`fork_shutter.stl`)** – print **upside down**, on the flat top face of the fork and plate (the STL is exported in this orientation).

| Setting | Value |
|---|---|
| Layer height | 0.12 mm |
| Wall loops | 6 (airtight gas channels) |
| Top/bottom shells | 6 / 6 |
| Infill | 100 % |
| Wall generator | Arachne |
| Supports | **Tree, on build plate only** (only the shutter rails and crossbar need them) |
| Brim | 5 mm outer brim |
| Minimum layer time | 8 s |
| Fan | 100 % from layer 3 |

The stand-alone parts (`airknife_breadboard.stl`, `shutter_frame.stl`, `airknife_horizontal.stl`, `airknife_diagonal.stl`) print **without supports** in their exported orientation.

**Shutter (`shutter.stl`)** – flat, band hooks up; 0.2 mm layers (exactly 8 layers = 1.6 mm), 100 % infill, **no brim**, elephant-foot compensation 0.2 mm. Lightly sand the long edges so it slides freely in the rail channels.

**After printing**

1. Tap the M5 gas port (printed at 4.2 mm).
2. Run a 0.5 mm shim through each nozzle slot.
3. Flatten the fitting's seating face if needed.
4. Leak-test: cover the slots, pressurise gently, brush on soapy water.
5. Check that air leaves both slots evenly (e.g. blow onto a wet glass slide).

## Hardware

| Item | Notes |
|---|---|
| 2× M6 bolts + large washers (18–24 mm OD) | breadboard mounting; holes are oversized (±3 mm) for alignment |
| Festo QSM-M5 push-in fitting | gas inlet (screws into the tapped M5 port) |
| Festo MHJ10-S-2,5-QS-6-HF fast solenoid valve | ~1 ms switching; driven at 24 V DC (≥ 1.7 A supply), separate 3–30 V trigger input |
| Festo QS-6H-4 (153041) | 6 mm plug-in to 4 mm tube at the valve outlet |
| 4 mm PU tube, short (15–20 cm) | valve → bracket; keep it short to keep the pulse sharp |
| Clean, dry, oil-free compressed air | |
| PTFE tube, 4 mm OD / 2 mm ID (~15–20 cm) | string guide from the shutter frame through the breadboard |
| Braided PE fishing line, ~0.15–0.2 mm | e.g. Fladen Maxximus Braid 0.16 mm; low stretch matters |
| 2 small rubber bands | shutter return |

## Assembly and setup

1. **Mount the bracket** on the breadboard with the plunger up. Lower the plunger slowly by hand and centre the grid between the two nozzle tips before tightening the bolts.
2. **Gas.** Screw the QSM-M5 fitting into the port, connect the valve output with a short 4 mm tube.
3. **Shutter.**
   - Slide the shutter into the rails and hook the two rubber bands between the shutter hooks and the posts under the rail fronts.
   - Push the PTFE tube into the socket in the rails' back crossbar, through the plate hole and the breadboard hole.
   - Thread the braid through it and tie it to the shutter tab (Palomar knot plus a drop of superglue).
4. **Connect to the release solenoid** behind the board (loop the line over rods so the solenoid's downward stroke pulls it). Use an adjustable clamp so you can set the slack to **zero** with the solenoid at rest.
5. **Check the timing.** Push the solenoid down slowly to its release point and confirm the shutter's front edge is clearly behind the tweezer before the plunger lets go. Re-check after the first few uses, as the line can settle.

### Operating sequence

1. Load the grid. The shutter is closed.
2. Fire the air pulse (typically tens of ms; tune pressure and duration by looking at the result).
3. Fire the release solenoid: the shutter opens, then the plunger drops.
4. Remove the tweezer **before** resetting the solenoid (the shutter closes again as it relaxes).

## Adapting to another plunger

Measure the parameters in the table above for your setup and pass them on the command line (or edit the defaults). Then read the clearance report every time: the plunge sweep checks assume the tweezer, lock ring and holder geometry you entered. The light-beam check assumes a beam along the grid normal through the grid centre (`light_r`).

## Safety

- Liquid ethane is flammable and liquid nitrogen causes cold burns and oxygen depletion. Follow your facility's cryogen procedures.
- Compressed air: wear eye protection while testing the nozzles. Never point them at anyone.
- PLA softens around 55–60 °C and gets brittle when cold. Avoid knocks while the parts are cold.
